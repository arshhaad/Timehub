# ⌚ Watch E-commerce System

A full-featured e-commerce platform for selling watches, including user and admin functionalities such as authentication, product browsing, cart management, order processing, and analytics dashboard.

---

## 🚀 Features

### 👤 User Module

#### 1. Authentication
- User registration
- Login / Logout
- Forgot & Reset Password

#### 2. Product Catalog
- Browse watch collections
- Search products
- Filter by category / brand
- View featured products

#### 3. Product Details
- Product images
- Pricing & discounts
- Specifications
- Availability status

#### 4. Shopping Cart
- Add / remove products
- Update quantity
- View cart summary

#### 5. Checkout & Payment
- Address selection
- Payment options (UPI / Card)
- Order confirmation

#### 6. Order Management
- View order history
- Track order status
- Cancel orders
- Request reschedule

#### 7. Wallet & Rewards
- Wallet balance
- Cashback transactions
- Reward points system

#### 8. User Profile
- Edit profile
- Manage addresses
- Change password

---

### 🛠 Admin Module

#### 1. Admin Authentication
- Secure login / logout
- Password reset

#### 2. Dashboard
- Total sales
- Total orders
- Total customers
- Recent orders overview

#### 3. Product Management
- Add / edit / delete products
- Upload product images

#### 4. Category & Brand Management
- Create categories
- Manage brands
- Assign products

#### 5. Inventory Management
- Stock updates
- Inventory tracking
- Low stock alerts

#### 6. Order Management
- View all orders
- Update order status
- Handle cancellations & reschedules

#### 7. Customer Management
- View users
- Block / unblock users
- View order history

#### 8. Marketing & Promotion
- Coupon management
- Ads & promotions
- Featured products

#### 9. Wallet & Cashback Management
- Manage cashback
- Control wallet transactions

#### 10. System Settings
- Payment configuration
- Shipping settings
- Tax management
- Admin profile settings
